# Selkirk

An expression parser using the [shunting yard algorithm][shunting-yard], with
additional features.

The name is a reference to [Selkirk Yard][selkirk-yard], a large freight
railroad yard originally built by the New York Central Railroad and now owned
by CSX as its main classification yard for the Northeastern United States.
